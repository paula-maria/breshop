# User Stories

## 1. Organização

As User Stories do projeto estão organizadas em:

* **Temas:** agrupam grandes áreas funcionais do sistema;
* **Épicos:** agrupam funcionalidades relacionadas dentro de um tema;
* **User Stories:** representam necessidades específicas dos usuários.

---

# Tema 1 — Contas e Perfis

## Épico 1.1 — Cadastro e Autenticação

### US01 — Cadastro de comprador

**Como** comprador,
**quero** me cadastrar na plataforma,
**para** poder navegar e comprar peças.

**Requisito relacionado:** RF01
**Prioridade:** Essencial

### US03 — Login

# 4. Rastreabilidade

Cada User Story está vinculada a um requisito funcional correspondente. Essa relação permite acompanhar a implementação das funcionalidades desde a especificação até o desenvolvimento.

```text
Tema
 └── Épico
      └── User Story
           └── Requisito Funcional
                └── Implementação
```

Exemplo:

```text
Gestão do Brechó
 └── Catálogo de Peças
      └── US07 — Cadastro de peças
           └── RF07 — Cadastro de peças
                └── Funcionalidade de cadastro no sistema
```
